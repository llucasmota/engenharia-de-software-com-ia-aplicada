## Como converter objetos JavaScript em Tensores 🧠

Ótima pergunta! Como eu mencionei, o **TensorFlow.js não entende objetos JavaScript** diretamente — ele precisa receber apenas números organizados em arrays (tensores). Então, o processo de conversão é essencial para que seus dados possam ser processados por algoritmos de machine learning.

### O Problema

Imagine que temos este array de pessoas:

```javascript
const pessoas = [
  { nome: "Erick", idade: 30, cor: "azul", localizacao: "São Paulo" },
  { nome: "Ana", idade: 25, cor: "vermelho", localizacao: "Rio" },
  { nome: "Carlos", idade: 40, cor: "verde", localizacao: "Curitiba" }
];
```

Aqui temos **nomes** (que não usaremos), uma **idade** (número), uma **cor preferida** (texto) e uma **localização** (texto). Precisamos transformar tudo isso em números!

### Passo 1: Remover dados desnecessários

O campo `nome` não traz informação útil para o algoritmo, então podemos descartá-lo.

### Passo 2: Normalizar valores numéricos

A **idade** é um número, mas precisa ser normalizada entre **0 e 1**. Usamos a fórmula de **min-max normalization**:

```
valor_normalizado = (valor - mínimo) / (máximo - mínimo)
```

Com idades 25, 30 e 40:
- **Erick** → (30 - 25) / (40 - 25) = **0.33**
- **Ana** → (25 - 25) / (40 - 25) = **0**
- **Carlos** → (40 - 25) / (40 - 25) = **1**

### Passo 3: Aplicar One-Hot Encoding para categorias

Para campos como **cor** e **localização**, onde cada opção é uma categoria distinta, usamos o **one-hot encoding**. A ideia é simples: cada opção vira uma coluna, e apenas a opção correspondente recebe **1**, enquanto as outras recebem **0**.

Veja como fica para as **cores** (azul, vermelho, verde):

|        | Azul | Vermelho | Verde |
|--------|------|----------|-------|
| Erick  | 1    | 0        | 0     |
| Ana    | 0    | 1        | 0     |
| Carlos | 0    | 0        | 1     |

E para as **localizações** (São Paulo, Rio, Curitiba):

|        | SP | Rio | Curitiba |
|--------|----|-----|----------|
| Erick  | 1  | 0   | 0        |
| Ana    | 0  | 1   | 0        |
| Carlos | 0  | 0   | 1        |

> 💡 **One-hot encoding** é como se você fizesse uma pesquisa de múltipla escolha: só pode marcar uma alternativa. Por isso só tem um "1" por linha!

### Passo 4: Montar o Tensor Final

Agora é só juntar tudo em um único array, mantendo a ordem das colunas:

```javascript
const tensorPessoas = tf.tensor2d([
  [0.33, 1, 0, 0, 1, 0, 0],  // Erick: idade=0.33, azul, SP
  [0.0,  0, 1, 0, 0, 1, 0],  // Ana: idade=0.0, vermelho, Rio
  [1.0,  0, 0, 1, 0, 0, 1]   // Carlos: idade=1.0, verde, Curitiba
]);

console.log(tensorPessoas.shape); // [3, 7] → 3 pessoas, 7 features cada
```

Cada linha representa uma pessoa e cada coluna representa uma **feature** (característica). O resultado é um tensor 2D (uma "tabela" de números) que o TensorFlow.js consegue processar! 🎉

### Resumo Rápido

| Tipo de dado | Como converter | Exemplo |
|---|---|---|
| Número | Normalizar entre 0 e 1 | `idade: 30` → `0.33` |
| Texto (poucas opções) | One-hot encoding | `cor: "azul"` → `[1, 0, 0]` |
| Desnecessário | Remover | `nome: "Erick"` → descartado |

É isso! O segredo é transformar tudo em números organizados em arrays, para que o TensorFlow.js consiga trabalhar com seus dados. Se tiver qualquer dúvida, é só perguntar! 😊
