## O que é One-Hot Encoding?

**One-hot encoding** (ou "codificação one-hot") é uma técnica usada para transformar dados **categóricos** (como texto ou rótulos) em **números** que uma rede neural consiga entender e processar.

Pense assim: redes neurais trabalham com números, elas não sabem o que significa "Erick", "Ana" ou "Carlos". Então precisamos converter esses dados em uma representação numérica que faça sentido.

### Analogia simples 🎯

Imagine um painel com interruptores. Para cada categoria possível, você tem um interruptor que pode estar **ligado (1)** ou **desligado (0)**. Apenas **um** interruptor fica ligado por vez — por isso o nome "one-hot" (um quente).

## Exemplo prático

Olhando o contexto que vimos, onde temos categorias como **Premium**, **Medium** e **Basic**, veja como ficaria:

| Categoria  | Premium | Medium | Basic |
|------------|---------|--------|-------|
| Premium    | 1       | 0      | 0     |
| Medium     | 0       | 1      | 0     |
| Basic      | 0       | 0      | 1     |

Cada categoria vira um vetor com o mesmo tamanho do número total de categorias, e apenas a posição correspondente recebe o valor `1`.

## Quando usar?

Você deve usar one-hot encoding quando:

1. **Seus dados de entrada são categóricos sem ordem natural** — por exemplo, cores (vermelho, azul, verde), cidades, nomes de pessoas (como Erick, Ana e Carlos do nosso exemplo).

2. **Seus dados de saída são categorias** — como no nosso exemplo, onde a camada de saída gera probabilidades para Premium (78%), Medium (12%) e Basic (10%). Essas saídas, na verdade, são representações one-hot durante o treinamento.

3. **Você não quer que o modelo interprete uma ordem errada** — se você codificasse como 1, 2, 3, o modelo poderia achar que "3 é maior que 1", o que não faz sentido para categorias sem hierarquia.

## Exemplo com TensorFlow.js

```javascript
// Suponha que temos 3 categorias: [Premium, Medium, Basic]
// Representadas como índices: 0, 1, 2

// One-hot encoding manual:
const categorias = ['Premium', 'Medium', 'Basic'];

function oneHotEncode(indice, totalClasses) {
  const vetor = new Array(totalClasses).fill(0);
  vetor[indice] = 1;
  return vetor;
}

// Premium -> [1, 0, 0]
// Medium  -> [0, 1, 0]
// Basic   -> [0, 0, 1]

console.log(oneHotEncode(0, 3)); // Premium: [1, 0, 0]
console.log(oneHotEncode(1, 3)); // Medium:  [0, 1, 0]
console.log(oneHotEncode(2, 3)); // Basic:   [0, 0, 1]
```

O TensorFlow.js também oferece utilitários como `tf.oneHot()` para facilitar:

```javascript
const tf = require('@tensorflow/tfjs');

// Índices das categorias
const indices = tf.tensor1d([0, 1, 2]); // Premium, Medium, Basic

// Aplica one-hot encoding
const oneHot = tf.oneHot(indices, 3); // 3 = número de classes
oneHot.print();
// Saída:
// [[1, 0, 0],
//  [0, 1, 0],
//  [0, 0, 1]]
```

## Resumindo

- **O quê?** Uma forma de converter categorias em vetores numéricos com zeros e um único `1`.
- **Por quê?** Redes neurais precisam de números, e essa técnica evita que o modelo crie relações de ordem incorretas entre categorias.
- **Quando?** Sempre que seus dados forem categóricos (nomes, tipos, rótulos) e não tiverem uma ordem natural.

É um conceito fundamental pra quem quer trabalhar com machine learning, e você vai usar bastante quando começar a preparar dados para treinar suas redes neurais! 🚀
